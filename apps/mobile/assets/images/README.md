# Ludo Lovers image assets

Upload approved image files into this directory.

## Current expected asset

- `ludo_lovers_logo.jpg` — the official Ludo Lovers logo used by the splash screen and home screen.

Keep filenames and letter casing exactly as referenced by the Flutter code. Once the logo is uploaded, register it under `flutter: assets:` in `apps/mobile/pubspec.yaml` (for example, `- assets/images/ludo_lovers_logo.jpg`). Do not register files that have not been uploaded yet, because Flutter builds can fail when a declared asset is missing.

Additional board, pawn, avatar, and UI images can be uploaded here when they are ready.
